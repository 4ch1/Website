# Курс по дей-трейдингу и тренажёр «куда пойдёт цена»

В этом репозитории две связанные части (добавлены поверх старого C#-проекта, который лежит в корне и не трогается):

- **[`course/`](course/README.md)** — курс из 12 модулей на русском (термины продублированы по-английски): свечи и сессии, структура рынка, объём и VWAP, индикаторы, свечные и графические паттерны, дей-трейдинг сетапы, мульти-таймфрейм, риск-менеджмент, план и журнал, психология, и честный разбор исследований. Каждый модуль — объяснение, размеченные примеры на **реальных** графиках (60+ картинок, построены скриптами из `course/figures/` на данных SPY/QQQ/IWM и крупных акций), типичные ошибки, чек-лист и мини-тест с ответами. Плюс [шпаргалка](course/cheatsheet.md) и [шаблоны плана и журнала](course/templates/).
- **[`trainer/`](trainer/README.md)** — локальный тренажёр на FastAPI + TypeScript + lightweight-charts: случайный кусок реального дня обрывается, вы прогнозируете вверх/вниз/флэт на N свечей (порог флэта через ATR), опционально ставите вход/стоп/цель на графике, затем свечи раскрываются с анимацией, считается результат прогноза и сделки в R, даётся алгоритмический разбор по правилам курса. Три режима (экзамен, обучающий, по теме), скрытие тикера и даты, строгое отсутствие lookahead (проверяется тестами), статистика в SQLite с базовыми линиями, биномиальными тестами, доверительными интервалами, expectancy и explicit «минимум раундов».

Запуск тренажёра одной командой: `cd trainer && make run`.
