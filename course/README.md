# Курс по дей-трейдингу (акции США) + тренажёр

Курс для инженера, который умеет программировать, но не умеет читать графики.
Все примеры — на реальных данных (SPY, QQQ, IWM и крупные акции), картинки построены скриптами
из `figures/` и воспроизводимы (`python figures/make_figures.py --from-frozen`).

Термины даны по-русски с английским в скобках, потому что все платформы, книги и чаты используют английские.

## Как проходить

1. Модуль читается за 30–60 минут. В конце чек-лист и мини-тест: не переходите дальше, пока не отвечаете на 8 из 10.
2. После модулей 2, 3, 5, 6, 7 — в тренажёр, режим «по теме», минимум 30 раундов по соответствующему тегу.
3. Модули 9–11 — прочитать до первой реальной сделки, а не после первого слива.
4. Модуль 12 — прочитать первым, если хочется понять, во что вы ввязываетесь.
